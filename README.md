## ⚙️ Core Development Principles

1. **Dark-First Architectural Aesthetic**: Near-black surfaces, controlled contrast, single signature accent, generous whitespace, technical precision.
2. **Strict Mandatory Workflow**: `INSPECT → PLAN → SCOPE → IMPLEMENT → TEST → VERIFY → DIFF REVIEW → REPORT`.
3. **Scope Protection**: Never alter unrelated pages or global systems when working on a scoped page update.
4. **Git Safety**: Safe commit operations, zero destructive history rewrites, and line-by-line diff inspections.
5. **Zero Invented Information**: All client stats, logos, testimonials, and legal claims use standard placeholders until explicitly confirmed.
